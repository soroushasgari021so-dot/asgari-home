ASGARI HOME - بسته تغییرات

محتویات:
- main.dart: کد اصلی به‌روزشده
- pubspec.yaml: وابستگی تقویم شمسی و تولید آیکون اندروید
- assets/asgari_logo.png: لوگوی کامل برای سربرگ صفحه اصلی
- assets/app_icon.png: نماد ساده‌شده خانه برای آیکون گوشی
- supabase_views_migration.sql: ساخت شمارنده بازدید در Supabase

مراحل اعمال:
1) از پروژه فعلی یک کپی پشتیبان بگیرید.
2) main.dart را جایگزین lib/main.dart کنید.
3) pubspec.yaml را جایگزین pubspec.yaml فعلی کنید.
4) پوشه assets را در ریشه پروژه قرار دهید.
5) در Supabase > SQL Editor فایل supabase_views_migration.sql را اجرا کنید.
6) در ریشه پروژه اجرا کنید:
   flutter pub get
   dart run flutter_launcher_icons
7) سپس build اندروید را اجرا کنید.

نکته تقویم:
تاریخ پیگیری همچنان به شکل میلادی استاندارد در دیتابیس ذخیره می‌شود تا اطلاعات قبلی و مرتب‌سازی فعلی حفظ شود؛ انتخاب و نمایش برای مدیر شمسی است.

نکته شمارنده بازدید:
بازدید با باز کردن جزئیات آگهی عمومی ثبت می‌شود، نه صرفاً با دیده‌شدن کارت در فهرست. شمارنده در پنل مدیر نمایش داده می‌شود. اجرای SQL مرحله 5 الزامی است.

این فایل‌ها هنوز در محیط واقعی Flutter build نشده‌اند؛ پس از اعمال، خروجی GitHub Actions یا خطای build را ارسال کنید تا اصلاح نهایی انجام شود.
