# ASGARI HOME – املاک عسگری

این بسته یک **اسکلت اولیه قابل ساخت** برای اپلیکیشن اندرویدی املاک عسگری است، نه نسخه نهایی عملیاتی.

## امکانات فعلی
- رابط اولیه فارسی و راست‌چین
- هویت بصری مشکی و طلایی
- اطلاعات تماس عمومی دفتر
- گردش ساخت APK با GitHub Actions

## ساخت APK
پس از بارگذاری کل محتویات این پوشه در شاخه `main` مخزن GitHub:
1. به زبانه Actions بروید.
2. اجرای workflow با نام Build Android APK را بررسی کنید.
3. پس از موفقیت، در صفحه اجرای workflow بخش Artifacts فایل `asgari-home-release-apk` را دانلود کنید.

## موارد تکمیل‌نشده
- احراز هویت واقعی دو مدیر
- اتصال Supabase و تنظیم امن RLS
- ثبت و ویرایش املاک و مدیریت مشتریان/مالکان
- آپلود تصاویر، بازدیدها، معاملات و گزارش‌ها
- تست روی دستگاه واقعی

کلیدهای خصوصی یا service_role را هرگز در مخزن یا کد اپلیکیشن قرار ندهید.
